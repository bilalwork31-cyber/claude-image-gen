Claude Code writes clean code and filthy decoration.

SVG blobs. Gradient "art". Emoji placeholders. Slop.

So I gave it a camera.

claude-image-gen generates real assets while Claude works. Heroes, logos, icons, transparent cutouts. Runs on the ChatGPT subscription you already pay for. No API key.

It queues. Enqueue returns in 150 ms, so Claude keeps building instead of waiting 90 seconds per image.

Two commands to install. MIT.
